# Data Science/Data Analytics Internship Project

# Student Performance & Titanic Survival Analysis

## Overview
This repository contains projects completed during my Data Science/Analysis with Python Internship at Maincrafts Technology.
The projects focus on applying data cleaning, exploratory data analysis (EDA), and visualization techniques to real-world datasets.
## Projects
### Task 1: Student Performance Analysis 

## Objective
* Analyze student data to understand factors affecting academic performance.
  
## Work Done

* Loaded and explored the dataset
* Cleaned missing and inconsistent data
* Performed univariate and bivariate analysis
* Created correlation heatmap
* Analyzed relationships between:
* Study time & grades
* Absences & performance
* Other influencing factors
  
## Visualizations

* Histograms (grade distribution)
* scatter plot(study time vs grade)
* Bar chart(male vs female average score)
  
## Key Insights

* Higher study time improves performance
* More absences reduce grades
* Multiple factors influence student outcomes
  
### Task 2: Titanic Survival Analysis

## Objective

Explore survival patterns and identify key factors affecting survival.

## Work Done

* Data cleaning (handled missing values like Age, Embarked)
* Performed EDA (Exploratory Data Analysis)
* Answered key questions:
* Who survived more (male/female)?
* Did passenger class affect survival?
* Survival rate by age group
* Created visualizations using Seaborn & Matplotlib

## Visualizations

* Bar chart (survival by gender)
* Bar chart (survival by class)
* Histogram (age distribution)

## Key Insights

* Females had higher survival rates
* First-class passengers were more likely to survive
* Age had a moderate impact on survival
## Data Preprocessing
* Handled missing values
* Converted categorical data
* Ensured clean and usable dataset
